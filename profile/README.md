# Eunomia

**Open-source eBPF systems community.**

We build and maintain open-source systems around eBPF, including userspace runtimes, observability tools, AI agent infrastructure, developer tooling, and GPU/Linux systems work. We also explore new systems research and publish reproducible artifacts, tutorials, and technical writing.

## Main projects

- [bpftime](https://github.com/eunomia-bpf/bpftime) — high-performance userspace eBPF runtime and extension framework for uprobes, USDT, syscall hooks, networking, GPU workflows, and other event sources. The work appeared at [OSDI 2025](https://www.usenix.org/conference/osdi25/presentation/zheng-yusheng).
- [AgentSight](https://github.com/eunomia-bpf/agentsight) — lightweight system-level observability for AI agents using eBPF, process monitoring, and runtime-level evidence.
- [eBPF Developer Tutorial](https://github.com/eunomia-bpf/bpf-developer-tutorial) — hands-on eBPF tutorials and runnable examples covering tracing, networking, sched-ext, userspace instrumentation, and GPU scenarios.
- [ActPlane](https://github.com/eunomia-bpf/ActPlane) — eBPF-based runtime policy enforcement for AI agents, including process, file, network, and information-flow controls.
- [eunomia-bpf](https://github.com/eunomia-bpf/eunomia-bpf) — toolchain for building, packaging, distributing, and running eBPF programs with JSON metadata and WebAssembly/OCI workflows.

## Research and experimental projects

- [llvmbpf](https://github.com/eunomia-bpf/llvmbpf) — LLVM JIT/AOT userspace eBPF VM and execution core used by bpftime.
- [wasm-bpf](https://github.com/eunomia-bpf/wasm-bpf) — WebAssembly-based eBPF tooling and runtime support for lightweight sandboxing and cloud-native deployment.
- [GPTtrace](https://github.com/eunomia-bpf/GPTtrace) — natural-language generation and exploration of eBPF tracing programs; part of our work on LLMs and kernel extensions.
- [gpu_ext](https://github.com/eunomia-bpf/gpu_ext) — research on extending eBPF-style programmability and observability to GPU execution paths.
